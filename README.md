# Simple Price Tracker

This is my project for the Java Internship. I wanted to make a tool that helps track prices on Hotline.ua.

### What it does:
* Search for products and get current prices.
* Save products you like to a local "Favorites" list.
* Updates the page without refreshing the whole window (using HTMX).

### Tech I used:
* **Java 21** and **Spring Boot** (the core of the app).
* **SQLite** (to store my favorite products).
* **Jsoup** (to get data from the website).
* **HTMX** (to make the UI feel smoother).

### Why I made it this way:
I'm 16 and currently studying in college. I chose SQLite because it's simple to set up, and HTMX because I wanted to learn how to make a dynamic site without a lot of complex JavaScript.
